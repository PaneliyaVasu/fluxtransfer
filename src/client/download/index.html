Install on Any Device

FluxTransfer is a Progressive Web App (PWA). Install it directly from your browser — no App Store, no Play Store, no downloads.

✅ Your browser supports one-click install! Click the button above.

phone_iphone iOS / iPadOS

iPhone & iPad

Install from Safari. iOS requires Safari for PWA home screen install.

  1. 1 Open fluxtransfer.app in Safari
  2. 2 Tap the Share button ⬆ at the bottom
  3. 3 Scroll down and tap Add to Home Screen
  4. 4 Tap Add to confirm
open_in_new Open in Safari to Install
android Android

Android Devices

Install directly as a Progressive Web App (PWA) on Chrome, Edge, or Firefox for Android.

  1. 1 Open in Chrome, Edge, or Firefox
  2. 2 Tap the ⋮ Menu button in the browser header
  3. 3 Tap Add to Home screen or Install app
desktop_windows Windows / macOS / Linux

Desktop

Install as a standalone desktop app from Chrome or Edge — works like a native app.

  1. 1 Open in Chrome or Edge
  2. 2 Click the ⊕ Install icon in the address bar or use the Install button below
  3. 3 Click Install in the dialog

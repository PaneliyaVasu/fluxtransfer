Security & Cryptography Architecture

Detailed breakdown of WebRTC encryption, PBKDF2 key derivation, and file integrity validation.

1. Transport Layer (DTLS / SRTP)

WebRTC DataChannels strictly mandate DTLS 1.2+ encryption for peer-to-peer data transport. Packets transmitted across STUN/TURN relays are encrypted end-to-end between peer browsers.

2. Application Payload Encryption (AES-256-GCM)

Files are sliced into 64KB ArrayBuffer chunks. Before sending, each chunk is encrypted using AES-GCM (256-bit key) with a unique 12-byte initialization vector (IV) generated via crypto.getRandomValues().

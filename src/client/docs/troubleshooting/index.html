Troubleshooting & Diagnostics

Common connection errors, NAT traversal issues, and resolutions.

1. "WebRTC connection failed" (Symmetric NAT)

Occurs when one or both devices are behind strict corporate firewalls, university Wi-Fi, or cellular CGNAT where STUN hole-punching fails.

Solution: Configure a TURN relay server (see TURN_SETUP_GUIDE.md in repository).

2. "Signaling server connection error"

The client could not connect to the WebSocket signaling server at ws://localhost:8080.

Solution: Ensure the Node.js signaling server process is running (npm start).

Device Compatibility & PWA Installation

FluxTransfer is engineered to operate seamlessly across all web-enabled operating systems without software installs.

Supported Browsers

Requires WebRTC and Web Crypto API support (available on 99%+ of browsers):

  • Google Chrome 80+
  • Apple Safari 13+
  • Mozilla Firefox 75+
  • Microsoft Edge 80+
  • Brave & Opera

iOS / iPadOS Safari PWA Setup

To install FluxTransfer on your iPhone or iPad home screen:

  1. Open Safari and navigate to fluxtransfer.app
  2. Tap the Share icon at the bottom of the screen
  3. Scroll down and tap Add to Home Screen

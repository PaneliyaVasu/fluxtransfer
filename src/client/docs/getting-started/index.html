Getting Started with FluxTransfer

FluxTransfer makes peer-to-peer file sharing simple without accounts, cloud uploads, or size restrictions.

How to Send a File

  1. Navigate to fluxtransfer.app on your browser.
  2. Click Choose File or drag and drop your file into the dropzone.
  3. Click Generate Code & Start Transfer. A unique 4-digit code and QR code will appear.
  4. Keep your browser tab open while waiting for the receiving peer to connect.

How to Receive a File

  1. On the receiving device, select the Receive File tab.
  2. Enter the 4-digit numeric code or tap Scan QR to use your camera.
  3. Click Connect. Direct WebRTC DataChannel streaming will begin immediately.
  4. Once completed, tap Save File to download your file.

Frequently Asked Questions

Everything you need to know about FluxTransfer P2P file sharing.

What is FluxTransfer? expand_more

FluxTransfer is a web application that enables direct, peer-to-peer file transfers between devices over the internet using browser WebRTC technology without uploading files to third-party servers.

Is there a file size limit? expand_more

No. Because files stream directly between devices without cloud storage caps, you can send files of any size (gigabytes or terabytes) subject only to available device memory and storage.

Are files uploaded to any cloud server? expand_more

No. Files never touch any cloud storage or intermediate server disk. The signaling server only exchanges room pairing signals.

Can I send files between iPhone and Windows? expand_more

Yes! FluxTransfer works seamlessly across all platforms with a web browser (Safari on iPhone, Chrome on Windows/Android, Edge, Firefox, etc.).

Do I need to create an account? expand_more

No registration, account creation, or email address is required.

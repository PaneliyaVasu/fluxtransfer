Security & Cryptographic Architecture

Technical disclosure of the cryptographic protocols and data isolation mechanisms enforced in FluxTransfer.

enhanced_encryption

WebRTC DTLS / SRTP Transport

All peer connections establish encrypted WebRTC DataChannels using DTLS 1.2+ handshake and SRTP. Wire-level data packet contents are encrypted before leaving your network device.

key

PBKDF2-SHA-256 Key Derivation

Application payload chunk encryption derives 256-bit keys using PBKDF2 with 100,000 iterations over SHA-256 from the session code and random salt.

lock

AES-256-GCM Chunk Encryption

File streams are partitioned into 64KB ArrayBuffer chunks. Each chunk is encrypted with AES-256-GCM and a unique 12-byte initialization vector (IV).

cloud_off

Zero Server File Storage

The WebSocket signaling server only exchanges room join signals and SDP offer/answer JSON metadata. File payload bytes are never sent to or stored on any server.

Source Code Transparency

The cryptographic methods outlined above are implemented natively in browser Web Crypto APIs (crypto.subtle) within p2p-engine.js and webrtc-engine.js without external proprietary binaries.
